# 国才笔译·备考台 PC（电脑版）

国才笔译备考工作台的**桌面宽屏版**，与手机版（https://haha666-star.github.io/guocai-prep-app/）并存，手机版不动。

- 线上地址：https://haha666-star.github.io/guocai-prep-app-pc/
- 部署方式：GitHub Pages 直接从 main 分支构建（文件在仓库根目录）
- 数据隔离：独立 localStorage key（`gcprep_pc_v1`），与手机版互不干扰

## v2.2 电脑版新增/改进

1. **桌面宽屏适配**：应用宽度 520px → 1200px，总览页 Hero 双栏、快捷入口/模块掌握度 4 列、术语/词组/句子列表双栏、题型构成 4 列、任务列表双栏、弹窗加宽；底部导航同步加宽。
2. **省赛·术语翻译+阐释**：增加「开始术语自测」按钮，点击后开始逐题练习，自评后统计正确率；一轮练完可「再来一轮」。
3. **省赛·长篇互译（完整闭环）**：
   - 每篇增加「开始翻译」按钮 → 显示输入框
   - 输入译文后点「提交译文」，自动对照参考译文计算**翻译正确率**（英文按词元、中文按二元组重合度），并给出等级（优秀 ≥85 / 良好 ≥70 / 及格 ≥60 / 需加强 <60）
   - 结果卡展示：正确率 + 等级 + 你的译文 vs 参考译文对照，可「重译一篇」
   - 顶部统计实时更新：术语翻译/阐释通过率 + 长篇互译正确率与通过篇数

## 部署说明

- 仓库：`haha666-star/guocai-prep-app-pc`（main）
